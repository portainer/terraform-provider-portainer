# portainer_addons (Data Source)

> **Business Edition only.** This endpoint does not exist in Portainer CE.

Lists the addons the connected Portainer offers, and reports the environment addon resources are served from.

## Example Usage

```hcl
data "portainer_addons" "all" {}

output "upgradable" {
  value = [for a in data.portainer_addons.all.addons : a.id if a.upgrade_available]
}
```

## Schema

### Optional

- `view` (String) Response view. Set to `switcher` for the lightweight app-switcher listing, which omits the catalog details and is readable by non-admin users. Leave unset for the full listing.

### Read-Only

- `addons` (List of Object) Addons the connected Portainer offers. (see [below for nested schema](#nestedatt--addons))
- `catalog_error` (String) Why the addon catalog could not be refreshed. When addons are still listed the listing is a cached copy; when it is empty nothing could be loaded. Admin-only, and never set on the `switcher` view.
- `environment_id` (Number) Identifier of the environment addon resources are read through, as reported by Portainer.
- `id` (String) Identifier of the data source.

When `catalog_error` is set and addons are still listed, the listing is a cached copy; when it is set and the list is empty, nothing could be loaded. The version and chart fields come from an admin-only part of the response, so they stay empty for a token that cannot see it.
