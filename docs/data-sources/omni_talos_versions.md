# portainer_omni_talos_versions (Data Source)

> **Business Edition only.** This endpoint does not exist in Portainer CE.

Lists the Talos versions a credential can provision.

## Example Usage

```hcl
data "portainer_omni_talos_versions" "supported" {
  credential_id = portainer_cloud_credentials.omni.id
}

output "newest_talos" {
  value = one(reverse(data.portainer_omni_talos_versions.supported.talos_versions))
}
```

## Schema

### Required

- `credential_id` (Number) Identifier of the Portainer cloud credential holding the Omni endpoint and service account key.

### Read-Only

- `compatibility` (List of Object) For each Talos version, the versions Portainer reports as compatible with it. (see [below for nested schema](#nestedatt--compatibility))
- `id` (String) Identifier of the data source.
- `talos_versions` (List of String) The Talos versions the credential can provision, sorted.

### `compatibility`
