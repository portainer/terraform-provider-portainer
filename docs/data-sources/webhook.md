# portainer_webhook (Data Source)

The `portainer_webhook` data source allows you to look up an existing Portainer webhook by its resource ID and endpoint ID. This is useful for retrieving the secret token of a webhook for automation purposes.

## Example Usage

### Look up a webhook by resource and endpoint

```hcl
data "portainer_webhook" "stack_webhook" {
  resource_id = "12"        # ID of the stack or service
  endpoint_id = 1           # ID of the environment
}

output "webhook_url" {
  value = "https://portainer.example.com/api/webhooks/${data.portainer_webhook.stack_webhook.token}"
}
```

### Required

- `endpoint_id` (Number) Identifier of the Portainer environment (endpoint) where the webhook is registered.
- `resource_id` (String) Identifier of the resource (e.g. service) the Portainer webhook is attached to. Combined with endpoint_id to find the webhook.

### Read-Only

- `token` (String, Sensitive) Token used to invoke the Portainer webhook URL.
- `webhook_type` (Number) Type of the Portainer webhook (e.g. service webhook, container webhook).
