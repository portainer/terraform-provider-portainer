# portainer_kubernetes_describe (Data Source)

Returns the `kubectl describe` output for a single Kubernetes resource, which is the fastest way to see why an object is unhealthy.

## Example Usage

```hcl
data "portainer_kubernetes_describe" "web_pod" {
  environment_id = 1
  kind           = "pod"
  name           = "web-6b8f7d9c4d-abcde"
  namespace      = "prod"
}

output "web_pod_details" {
  value = data.portainer_kubernetes_describe.web_pod.describe
}
```

## Schema

### Required

- `environment_id` (Number) Environment (endpoint) identifier of the Kubernetes environment to query.
- `kind` (String) Kind of the resource to describe, as `kubectl describe` takes it (for example `pod`, `deployment` or `node`).
- `name` (String) Name of the resource to describe.

### Optional

- `namespace` (String) Namespace of the resource. Leave unset for a cluster-scoped kind such as `node`.

### Read-Only

- `describe` (String) Output of `kubectl describe` for the resource, as plain text.
- `id` (String) Identifier of the resource.
