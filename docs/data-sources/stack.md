# portainer_stack (Data Source)

The `portainer_stack` data source allows you to look up an existing Portainer stack by its name within a specific environment.

## Example Usage

### Look up a stack by name

```hcl
data "portainer_environment" "local" {
  name = "local"
}

data "portainer_stack" "nginx" {
  name        = "nginx-stack"
  endpoint_id = data.portainer_environment.local.id
}

output "stack_id" {
  value = data.portainer_stack.nginx.id
}
```

## Schema

### Required

- `endpoint_id` (Number) Identifier of the Portainer environment (endpoint) where the stack is deployed.
- `name` (String) Name of the Portainer stack to look up. Combined with endpoint_id to uniquely identify the stack.

### Read-Only

- `id` (String) Identifier of the resource.
- `swarm_id` (String) Identifier of the Docker Swarm cluster the stack is deployed to. Empty for non-Swarm stacks.
- `type` (Number) Type of the Portainer stack: 1 = Swarm, 2 = Compose, 3 = Kubernetes.

## Notes on Arguments and Attributes

- `id`: ID of the Portainer stack.
