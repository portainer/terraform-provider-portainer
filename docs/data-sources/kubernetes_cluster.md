# portainer_kubernetes_cluster (Data Source)

Describes a Kubernetes cluster behind a Portainer environment: its version, whether RBAC is on, what Portainer counts in it, and how much room is left for a new workload.

## Example Usage

```hcl
data "portainer_kubernetes_cluster" "prod" {
  environment_id = 1
}

# RBAC-dependent resources are pointless without it.
resource "portainer_kubernetes_namespace_access" "team" {
  count = data.portainer_kubernetes_cluster.prod.rbac_enabled ? 1 : 0
  # ...
}
```

## Schema

### Required

- `environment_id` (Number) Environment (endpoint) identifier of the Kubernetes environment to describe.

### Read-Only

- `applications_count` (Number) Number of applications Portainer sees in the cluster.
- `config_maps_count` (Number) Number of ConfigMaps in the cluster.
- `id` (String) Identifier of the resource.
- `ingresses_count` (Number) Number of ingresses in the cluster.
- `major` (String) Major version component of the cluster.
- `max_cpu` (Number) Largest CPU allocation a single workload could still request, in millicores, across the cluster's nodes.
- `max_memory` (Number) Largest memory allocation a single workload could still request, in bytes, across the cluster's nodes.
- `minor` (String) Minor version component of the cluster.
- `namespaces_count` (Number) Number of namespaces visible to the API token.
- `platform` (String) Platform the API server runs on, such as `linux/amd64`.
- `rbac_enabled` (Boolean) Whether RBAC is enabled on the cluster. Roles, role bindings and namespace access policies only take effect when it is.
- `secrets_count` (Number) Number of secrets in the cluster.
- `services_count` (Number) Number of services in the cluster.
- `supports_pod_restart` (Boolean) Whether the cluster is new enough for Portainer's pod restart action.
- `version` (String) Full Kubernetes version of the cluster, as reported by the API server (for example `v1.31.4+k3s1`).
- `volumes_count` (Number) Number of volumes in the cluster.

## Attributes Reference

The counters come from Portainer's dashboard endpoint and reflect what the API token can see, not necessarily the whole cluster.
