# portainer_oidc_client_sessions (Data Source)

> **Requires Portainer Business Edition 3.1 or later.** On Community Edition or an older server the read fails with an error that says so.

**Portainer Business Edition 3.1.0 serves the OIDC provider only when started with the `oidc` feature flag**: `--feat=oidc` (or the environment variable `FEATURE_FLAG=oidc`; Helm chart: `--set "feature.flags[0]=--feat=oidc"`). Without it every OIDC API call fails with an error that says so.

Lists the sessions of a client of Portainer's built-in OIDC provider (`GET /oidc_clients/{id}/sessions`): one per sign-in. Sessions are ended with [`portainer_oidc_client_sessions_end`](../resources/oidc_client_sessions_end.md).

## Example Usage

```hcl
data "portainer_oidc_client_sessions" "grafana" {
  client_id = tonumber(portainer_oidc_client.grafana.id)
}

output "grafana_signed_in_users" {
  value = distinct(data.portainer_oidc_client_sessions.grafana.sessions[*].username)
}
```
