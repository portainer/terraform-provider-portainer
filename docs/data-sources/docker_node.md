# portainer_docker_node (Data Source)

The `portainer_docker_node` data source allows you to look up an existing Docker node (host) within a Portainer Swarm environment.

## Example Usage

### Look up a Swarm node by hostname

```hcl
data "portainer_docker_node" "worker1" {
  endpoint_id = 1
  hostname    = "swarm-worker-01"
}

output "node_role" {
  value = data.portainer_docker_node.worker1.role
}
```

## Schema

### Required

- `endpoint_id` (Number) ID of the Portainer environment (Docker Swarm cluster) where the node is located.
- `hostname` (String) Hostname of the Docker Swarm node to look up.

### Read-Only

- `id` (String) Identifier of the resource.
- `role` (String) Role of the Swarm node (worker or manager).
- `status` (String) Current status state of the Swarm node (e.g., ready, down, disconnected).

## Notes on Arguments and Attributes

- `id`: ID of the Docker node.
