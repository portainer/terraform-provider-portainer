# portainer_oidc_clients (Data Source)

> **Requires Portainer Business Edition 3.1 or later.** On Community Edition or an older server the read fails with an error that says so.

**Portainer Business Edition 3.1.0 serves the OIDC provider only when started with the `oidc` feature flag**: `--feat=oidc` (or the environment variable `FEATURE_FLAG=oidc`; Helm chart: `--set "feature.flags[0]=--feat=oidc"`). Without it every OIDC API call fails with an error that says so.

Lists the clients of Portainer's built-in OIDC provider (`GET /oidc_clients`), optionally filtered by name. Secret values are never returned; each client lists its secrets by ID, hint and expiry, which is how to find the ID to import a secret into [`portainer_oidc_client_secret`](../resources/oidc_client_secret.md).

## Example Usage

```hcl
data "portainer_oidc_clients" "grafana" {
  name = "Grafana"
}

output "grafana_oauth_client_id" {
  value = data.portainer_oidc_clients.grafana.clients[0].client_id
}

output "grafana_secret_ids" {
  value = data.portainer_oidc_clients.grafana.clients[0].secrets[*].id
}
```
