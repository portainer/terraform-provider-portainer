# portainer_app_templates (Data Source)

Lists Portainer's application template catalogue, and optionally fetches the stack file of one template.

## Example Usage

```hcl
data "portainer_app_templates" "catalogue" {}

output "available_templates" {
  value = [for t in data.portainer_app_templates.catalogue.templates : t.title]
}

# Deploy a stack straight from a catalogue template.
data "portainer_app_templates" "wordpress" {
  template_id = 12
}
```

## Schema

### Optional

- `template_id` (Number) Identifier of a template whose stack file should also be fetched. Leave unset to only list the catalogue.

### Read-Only

- `file_content` (String) Stack file of the template named by `template_id`, empty when that argument is unset.
- `id` (String) Identifier of the data source, built from the catalogue version.
- `templates` (List of Object) Templates in the catalogue Portainer is configured to serve. (see [below for nested schema](#nestedatt--templates))
- `version` (String) Version of the template catalogue Portainer is serving.
