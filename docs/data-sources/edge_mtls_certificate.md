# portainer_edge_mtls_certificate (Data Source)

> **Business Edition only.** This endpoint does not exist in Portainer CE.

Reads the parsed X.509 details of the certificate Portainer presents to edge agents.

## Example Usage

```hcl
data "portainer_edge_mtls_certificate" "current" {}

output "edge_mtls_certificate_expiry" {
  value = data.portainer_edge_mtls_certificate.current.valid_not_after
}
```

## Schema

### Read-Only

- `common_name` (String) Common name of the certificate's subject.
- `configured` (Boolean) Whether Portainer has an edge mTLS certificate configured. Every other attribute is empty when it does not.
- `extended_key_usages` (List of String) Extended key usages the certificate permits.
- `id` (String) Always `portainer-edge-mtls-certificate`.
- `is_certificate_authority` (Boolean) Whether the certificate carries the CA basic constraint. Portainer's own edge mTLS certificate is a leaf, so this reports `false`.
- `issuer_common_name` (String) Common name of the certificate's issuer, which is the edge mTLS CA.
- `key_usages` (List of String) Key usages the certificate permits.
- `organization` (List of String) Organization of the certificate's subject.
- `public_key_algorithm` (String) Algorithm of the certificate's public key.
- `public_key_size` (Number) Size of the certificate's public key, in bits.
- `serial_number` (String) Serial number of the certificate.
- `sha256_fingerprint` (String) SHA-256 fingerprint of the certificate, which is what to compare against when rotating it.
- `signature_algorithm` (String) Algorithm the certificate is signed with.
- `subject_alt_dns_names` (List of String) DNS names in the certificate's subject alternative name extension.
- `subject_alt_ip_addresses` (List of String) IP addresses in the certificate's subject alternative name extension.
- `valid_not_after` (String) End of the certificate's validity period. Watch this to rotate before edge agents stop connecting.
- `valid_not_before` (String) Start of the certificate's validity period.
- `version` (Number) X.509 version of the certificate.

This data source is read-only. Portainer takes its edge mTLS material from files on the host, so there is no endpoint to write it through - use `valid_not_after` to drive an alert or a rotation workflow before edge agents stop connecting.
