# portainer_helm_chart (Data Source)

Reads from a Helm repository through Portainer: the repository index, or a chart's default values, readme or metadata.

## Example Usage

```hcl
# The repository index.
data "portainer_helm_chart" "repo" {
  repo = "https://charts.bitnami.com/bitnami"
}

# A chart's default values, to diff against your own.
data "portainer_helm_chart" "nginx_values" {
  repo    = "https://charts.bitnami.com/bitnami"
  chart   = "nginx"
  command = "values"
}

output "nginx_defaults" {
  value = data.portainer_helm_chart.nginx_values.content
}
```

## Schema

### Required

- `repo` (String) URL of the Helm repository to read from.

### Optional

- `chart` (String) Chart to inspect. Leave unset to fetch the repository index instead.
- `command` (String) What to fetch for `chart`: its default `values`, its `readme`, or the `chart` metadata. Ignored when `chart` is unset.
- `version` (String) Chart version to inspect. Leave unset for the newest one.

### Read-Only

- `content` (String) The requested document, as returned by Portainer: the repository index when `chart` is unset, otherwise the chart's values, readme or metadata.
- `id` (String) Identifier of the data source, built from the command, repository and chart.

## Attributes Reference

Both endpoints answer with a document — YAML or Markdown — rather than JSON, so `content` is the raw text.
