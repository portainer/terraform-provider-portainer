# portainer_system (Data Source)

The `portainer_system` data source describes the Portainer instance itself: its version, edition, scale and whether it has been initialised. It folds Portainer's four system endpoints plus the administrator check into one lookup.

Its most useful attribute is `server_version`, which lets a configuration gate resources on the Portainer release — several resources in this provider need 2.45 or newer.

## Example Usage

```hcl
data "portainer_system" "this" {}

# Only manage a deployment's scale where the native API exists.
resource "portainer_kubernetes_deployment_scale" "web" {
  count = tonumber(split(".", data.portainer_system.this.server_version)[1]) >= 45 ? 1 : 0

  environment_id  = 1
  namespace       = "prod"
  deployment_name = "web"
  replicas        = 3
}

output "portainer_scale" {
  value = "${data.portainer_system.this.agents} agents, ${data.portainer_system.this.edge_agents} edge agents, ${data.portainer_system.this.nodes} nodes"
}
```

## Arguments Reference

This data source takes no arguments.

## Schema

### Read-Only

- `addons_availability` (String) Why addons can or cannot be installed: `available`, `kubernetes-required`, `fips-mode` or `encryption-key-required`. Servers before 3.0 report no reason, only `available` or `unavailable`; empty when the server reports nothing.
- `addons_available` (Boolean) Whether addons can be installed on this instance.
- `admin_initialized` (Boolean) Whether an administrator account already exists. False means the instance is still awaiting its initial setup.
- `agents` (Number) Number of standard agents connected to this instance.
- `database_version` (String) Schema version of Portainer's database.
- `edge_agents` (Number) Number of Edge agents connected to this instance.
- `id` (String) Identifier of the data source.
- `instance_id` (String) Unique identifier of this Portainer instance.
- `latest_version` (String) Newest Portainer version available upstream, empty when the instance cannot reach the update service.
- `nodes` (Number) Total number of nodes across every environment, which is what Portainer licences against.
- `platform` (String) Container platform Portainer itself runs on, such as `docker` or `kubernetes`.
- `server_edition` (String) Portainer edition as the server reports it: `CE`, or `EE` for Business Edition.
- `server_version` (String) Server version reported by the version endpoint. Use it to gate configuration on the Portainer release, for example a resource that needs 2.45 or newer.
- `update_available` (Boolean) Whether a newer Portainer version than the running one is available.
- `version` (String) Version of the running Portainer instance, as reported by its status endpoint.
- `version_support` (String) Support status of the running version, such as `STS` or `LTS`.

`/status` is Portainer's deprecated alias of `/system/status` and returns the same object, so only the current path is called.
