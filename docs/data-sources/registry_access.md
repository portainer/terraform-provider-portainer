# portainer_registry_access (Data Source)

The `portainer_registry_access` data source allows you to retrieve the access role (policy) of a specific team or user on a registry within a specific endpoint.

### Example Usage

```hcl
// Querying a team's access to a registry
data "portainer_registry_access" "team_access" {
  registry_id = 3
  endpoint_id = 1
  team_id     = 2
}

output "team_role" {
  value = data.portainer_registry_access.team_access.role_id
}

// Querying a user's access to a registry
data "portainer_registry_access" "user_access" {
  registry_id = 3
  endpoint_id = 1
  user_id     = 5
}
```

### Required

- `endpoint_id` (Number) Identifier of the Portainer endpoint to which the registry access policy applies.

### Read-Only

- `id` (String) Identifier of the access policy: <registry_id>/<endpoint_id>/team/<team_id> or <registry_id>/<endpoint_id>/user/<user_id>.
- `role_id` (Number) Role identifier assigned to the user or team for the registry on the given endpoint.

- `team_id`: ID of the team (must provide team or user).
- `user_id`: ID of the user (must provide team or user).
