# portainer_gitops_source (List Resource)

The `portainer_gitops_source` list resource lists the Portainer GitOps sources (Business Edition) for `terraform query`, so existing objects can be found and imported into the [`portainer_gitops_source`](../resources/gitops_source.md) resource. Each result carries the resource identity (`id`) and, with `include_resource = true`, the full resource as an import would read it.

> **Requirements:** Terraform 1.14 or later (`terraform query`, `*.tfquery.hcl` files). Importing the results by identity needs Terraform 1.12 or later. OpenTofu does not support list resources.

## Example Usage

### List everything (`main.tfquery.hcl`)

```hcl
list "portainer_gitops_source" "all" {
  provider = portainer
}
```

### Filter and include the full resource

```hcl
list "portainer_gitops_source" "selected" {
  provider         = portainer
  include_resource = true

  config {
    name = "infra"
  }
}
```

```shell
terraform query
# Write resource and import blocks for every result:
terraform query -generate-config-out=generated.tf
```

## Arguments Reference

Arguments of the `config` block; all are optional and combine. Without any, every object is listed. The `list` block itself takes Terraform's `provider`, `include_resource` (default `false`) and `limit` (default `100`).

## Attributes Reference

Each result has the source name as its display name and the identity:

| Name | Description |
|------|-------------|
| `id` | Numeric Portainer ID, the resource's `id` and import ID. |

With `include_resource = true` a result also holds every attribute of the [`portainer_gitops_source`](../resources/gitops_source.md) resource, read the way an import reads it: `administrators_only` at its default `false` (Portainer does not return it), passwords never.
