# portainer_endpoint_group (List Resource)

The `portainer_endpoint_group` list resource lists the Portainer environment (endpoint) groups, the built-in *Unassigned* group included for `terraform query`, so existing objects can be found and imported into the [`portainer_endpoint_group`](../resources/endpoint_group.md) resource. Each result carries the resource identity (`id`) and, with `include_resource = true`, the full resource as an import would read it.

> **Requirements:** Terraform 1.14 or later (`terraform query`, `*.tfquery.hcl` files). Importing the results by identity needs Terraform 1.12 or later. OpenTofu does not support list resources.

## Example Usage

### List everything (`main.tfquery.hcl`)

```hcl
list "portainer_endpoint_group" "all" {
  provider = portainer
}
```

### Filter and include the full resource

```hcl
list "portainer_endpoint_group" "selected" {
  provider         = portainer
  include_resource = true

  config {
    name = "production"
  }
}
```

```shell
terraform query
# Write resource and import blocks for every result:
terraform query -generate-config-out=generated.tf
```

## Arguments Reference

Arguments of the `config` block; all are optional and combine. Without any, every object is listed. The `list` block itself takes Terraform's `provider`, `include_resource` (default `false`) and `limit` (default `100`).

## Attributes Reference

Each result has the display name the group name and the identity:

| Name | Description |
|------|-------------|
| `id` | Numeric Portainer ID, the resource's `id` and import ID. |

With `include_resource = true` a result also holds every attribute of the [`portainer_endpoint_group`](../resources/endpoint_group.md) resource, read the way an import reads it.
