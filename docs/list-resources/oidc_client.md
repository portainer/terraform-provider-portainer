# portainer_oidc_client (List Resource)

> **Requires Portainer Business Edition 3.1 or later.**

**Portainer Business Edition 3.1.0 serves the OIDC provider only when started with the `oidc` feature flag**: `--feat=oidc` (or the environment variable `FEATURE_FLAG=oidc`; Helm chart: `--set "feature.flags[0]=--feat=oidc"`). Without it every OIDC API call fails with an error that says so.

The `portainer_oidc_client` list resource lists the clients of Portainer's built-in OIDC provider for `terraform query`, so existing objects can be found and imported into the [`portainer_oidc_client`](../resources/oidc_client.md) resource. Each result carries the resource identity (`id`) and, with `include_resource = true`, the full resource as an import would read it.

> **Requirements:** Terraform 1.14 or later (`terraform query`, `*.tfquery.hcl` files). Importing the results by identity needs Terraform 1.12 or later. OpenTofu does not support list resources.

## Example Usage

### List everything (`main.tfquery.hcl`)

```hcl
list "portainer_oidc_client" "all" {
  provider = portainer
}
```

### Filter and include the full resource

```hcl
list "portainer_oidc_client" "selected" {
  provider         = portainer
  include_resource = true

  config {
    name = "Grafana"
  }
}
```

```shell
terraform query
# Write resource and import blocks for every result:
terraform query -generate-config-out=generated.tf
```

## Arguments Reference

Arguments of the `config` block; all are optional and combine. Without any, every object is listed. The `list` block itself takes Terraform's `provider`, `include_resource` (default `false`) and `limit` (default `100`).

## Attributes Reference

Each result has the client name as its display name and the identity:

| Name | Description |
|------|-------------|
| `id` | Numeric Portainer ID, the resource's `id` and import ID. |

With `include_resource = true` a result also holds every attribute of the [`portainer_oidc_client`](../resources/oidc_client.md) resource, read the way an import reads it: without the first client secret, which Portainer never returns again.
