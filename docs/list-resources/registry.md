# portainer_registry (List Resource)

The `portainer_registry` list resource lists the Portainer registries for `terraform query`, so existing objects can be found and imported into the [`portainer_registry`](../resources/registry.md) resource. Each result carries the resource identity (`id`) and, with `include_resource = true`, the full resource as an import would read it.

> **Requirements:** Terraform 1.14 or later (`terraform query`, `*.tfquery.hcl` files). Importing the results by identity needs Terraform 1.12 or later. OpenTofu does not support list resources.

## Example Usage

### List everything (`main.tfquery.hcl`)

```hcl
list "portainer_registry" "all" {
  provider = portainer
}
```

### Filter and include the full resource

```hcl
list "portainer_registry" "selected" {
  provider         = portainer
  include_resource = true

  config {
    type = 3
  }
}
```

```shell
terraform query
# Write resource and import blocks for every result:
terraform query -generate-config-out=generated.tf
```

## Arguments Reference

Arguments of the `config` block; all are optional and combine. Without any, every object is listed. The `list` block itself takes Terraform's `provider`, `include_resource` (default `false`) and `limit` (default `100`).

## Schema

### Optional

- `name` (String) Only list the registry with exactly this name.
- `type` (Number) Only list the registries of this type (1 = Quay, 2 = Azure, 3 = custom, 4 = GitLab, 5 = ProGet, 6 = Docker Hub, 7 = ECR, 8 = GitHub).

## Attributes Reference

Each result has the display name the registry name and the identity:

| Name | Description |
|------|-------------|
| `id` | Numeric Portainer ID, the resource's `id` and import ID. |

With `include_resource = true` a result also holds every attribute of the [`portainer_registry`](../resources/registry.md) resource, read the way an import reads it.

`password` and `password_wo` are never part of a result: Portainer does not return them.
