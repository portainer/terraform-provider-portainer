# portainer_edge_stack (List Resource)

The `portainer_edge_stack` list resource lists the Portainer Edge stacks for `terraform query`, so existing objects can be found and imported into the [`portainer_edge_stack`](../resources/edge_stack.md) resource. Each result carries the resource identity (`id`) and, with `include_resource = true`, the full resource as an import would read it.

> **Requirements:** Terraform 1.14 or later (`terraform query`, `*.tfquery.hcl` files). Importing the results by identity needs Terraform 1.12 or later. OpenTofu does not support list resources.

## Example Usage

### List everything (`main.tfquery.hcl`)

```hcl
list "portainer_edge_stack" "all" {
  provider = portainer
}
```

### Filter and include the full resource

```hcl
list "portainer_edge_stack" "selected" {
  provider         = portainer
  include_resource = true

  config {
    name = "web"
  }
}
```

```shell
terraform query
# Write resource and import blocks for every result:
terraform query -generate-config-out=generated.tf
```

## Arguments Reference

Arguments of the `config` block; all are optional and combine. Without any, every object is listed. The `list` block itself takes Terraform's `provider`, `include_resource` (default `false`) and `limit` (default `100`).

## Attributes Reference

Each result has the Edge stack name as its display name and the identity:

| Name | Description |
|------|-------------|
| `id` | Numeric Portainer ID, the resource's `id` and import ID. |

With `include_resource = true` a result also holds every attribute of the [`portainer_edge_stack`](../resources/edge_stack.md) resource, read the way an import reads it (per-device configurations and a non-default `stagger_config` included). The stack file content, registry credentials and other values Portainer does not return are not part of a result.
