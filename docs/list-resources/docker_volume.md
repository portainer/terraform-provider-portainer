# portainer_docker_volume (List Resource)

The `portainer_docker_volume` list resource lists the Docker volumes of a Portainer environment for `terraform query`, so existing objects can be found and imported into the [`portainer_docker_volume`](../resources/docker_volume.md) resource. Each result carries the resource identity (`endpoint_id`, `name`) and, with `include_resource = true`, the full resource as an import would read it.

> **Requirements:** Terraform 1.14 or later (`terraform query`, `*.tfquery.hcl` files). Importing the results by identity needs Terraform 1.12 or later. OpenTofu does not support list resources.

## Example Usage

### List everything in one environment (`main.tfquery.hcl`)

```hcl
list "portainer_docker_volume" "all" {
  provider = portainer

  config {
    endpoint_id = 1
  }
}
```

### Filter and include the full resource

```hcl
list "portainer_docker_volume" "selected" {
  provider         = portainer
  include_resource = true

  config {
    endpoint_id = 1
    name        = "data"
  }
}
```

```shell
terraform query
# Write resource and import blocks for every result:
terraform query -generate-config-out=generated.tf
```

## Arguments Reference

Arguments of the `config` block. `endpoint_id` is required (Docker objects belong to one environment); `name` narrows the list. The `list` block itself takes Terraform's `provider`, `include_resource` (default `false`) and `limit` (default `100`).

## Schema

### Required

- `endpoint_id` (Number) ID of the Portainer environment (endpoint) whose volumes are listed.

### Optional

- `name` (String) Only list the volumes with exactly this name.

## Attributes Reference

Each result has the volume name as its display name and the identity:

| Identity attribute | Description |
|--------------------|-------------|
| `endpoint_id` | Numeric ID of the Portainer environment. |
| `name` | Docker volume name (the resource's `id` is `<endpoint_id>:<name>`). |

With `include_resource = true` a result also holds every attribute of the [`portainer_docker_volume`](../resources/docker_volume.md) resource, read the way an import reads it.
