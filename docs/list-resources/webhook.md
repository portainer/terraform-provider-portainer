# portainer_webhook (List Resource)

The `portainer_webhook` list resource lists the Portainer service and container webhooks for `terraform query`, so existing objects can be found and imported into the [`portainer_webhook`](../resources/webhook.md) resource. Each result carries the resource identity (`id`) and, with `include_resource = true`, the full resource as an import would read it.

> **Requirements:** Terraform 1.14 or later (`terraform query`, `*.tfquery.hcl` files). Importing the results by identity needs Terraform 1.12 or later. OpenTofu does not support list resources.

## Example Usage

### List everything (`main.tfquery.hcl`)

```hcl
list "portainer_webhook" "all" {
  provider = portainer
}
```

### Filter and include the full resource

```hcl
list "portainer_webhook" "selected" {
  provider         = portainer
  include_resource = true

  config {
    endpoint_id = 1
    resource_id = "my-service-id"
  }
}
```

```shell
terraform query
# Write resource and import blocks for every result:
terraform query -generate-config-out=generated.tf
```

## Arguments Reference

Arguments of the `config` block; all are optional and combine. Without any, every object is listed. The `list` block itself takes Terraform's `provider`, `include_resource` (default `false`) and `limit` (default `100`).

## Schema

### Optional

- `endpoint_id` (Number) Only list the webhooks of this environment (endpoint).
- `resource_id` (String) Only list the webhooks of this resource (service or container ID).

## Attributes Reference

Each result has the display name `webhook <id> (<resource_id>)` and the identity:

| Name | Description |
|------|-------------|
| `id` | Numeric Portainer ID, the resource's `id` and import ID. |

With `include_resource = true` a result also holds every attribute of the [`portainer_webhook`](../resources/webhook.md) resource, read the way an import reads it.

The webhook `token` is part of a result (it is sensitive). Business Edition only lists the webhooks of one resource: set both `endpoint_id` and `resource_id` there; Community Edition can list them all.
