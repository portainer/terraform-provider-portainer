# portainer_oidc_user_sessions_end (Action)

> **Requires Portainer Business Edition 3.1 or later.**

**Portainer Business Edition 3.1.0 serves the OIDC provider only when started with the `oidc` feature flag**: `--feat=oidc` (or the environment variable `FEATURE_FLAG=oidc`; Helm chart: `--set "feature.flags[0]=--feat=oidc"`). Without it every OIDC API call fails with an error that says so.

Signs a user out of every client and add-on that signed them in through Portainer's OIDC provider. Their tokens are revoked at once.

> **Requirements:** Terraform >= 1.14 (actions). OpenTofu does not support actions; there, and with older Terraform, use the [`portainer_oidc_user_sessions_end` resource](../resources/oidc_user_sessions_end.md), which runs the same operation when it is created.

## Example Usage

### Run it on demand

```hcl
action "portainer_oidc_user_sessions_end" "now" {
  config {
    user_id = var.user_id
  }
}
```

```shell
terraform apply -invoke action.portainer_oidc_user_sessions_end.now
```

## Lifecycle & Behavior

- The action runs only when it is invoked: from an `action_trigger` or with `terraform apply -invoke`. Nothing is stored in state.
- It sends the same request as the `portainer_oidc_user_sessions_end` resource does when it is created, and fails the apply with the same errors.
