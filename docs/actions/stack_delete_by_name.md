# portainer_stack_delete_by_name (Action)

The `portainer_stack_delete_by_name` action removes every Kubernetes stack with a name from an environment, the only way to clear a stack Terraform has no ID for, typically one deployed outside Portainer. A stack that is already gone is not an error.

> **Requirements:** Terraform >= 1.14 (actions). OpenTofu does not support actions; there, and with older Terraform, use the [`portainer_stack_delete_by_name` resource](../resources/stack_delete_by_name.md), which runs the same operation when it is created.

## Example Usage

### Run it from a lifecycle `action_trigger`

```hcl
action "portainer_stack_delete_by_name" "legacy" {
  config {
    endpoint_id = 1
    name        = "legacy"
    namespace   = "shop"
    external    = true
  }
}

resource "portainer_kubernetes_namespace" "shop" {
  # ...

  lifecycle {
    action_trigger {
      events  = [after_create]
      actions = [action.portainer_stack_delete_by_name.legacy]
    }
  }
}
```

### Run it on demand

```shell
terraform apply -invoke action.portainer_stack_delete_by_name.legacy
```

## Lifecycle & Behavior

- The action runs only when it is invoked: from an `action_trigger` on the events listed there, or with `terraform apply -invoke`. A plan lists the invocations it would run; nothing is stored in state, so there is nothing to destroy and no `triggers` argument is needed to run it again.
- It sends the same requests as the `portainer_stack_delete_by_name` resource does when it is created, with the same defaults, and fails the apply with the same errors.

## Schema

### Required

- `endpoint_id` (Number) Identifier of the environment the stack was deployed to.
- `name` (String) Name of the Kubernetes stack to remove. Every stack with this name in the target environment is removed.
- `namespace` (String) Kubernetes namespace the stack was deployed into. Portainer requires it, even though its API specification does not list it.

### Optional

- `external` (Boolean) Whether the stack was created outside Portainer. Set it to true to remove a stack Portainer only discovered, rather than one it deployed. Defaults to `false`.

## Attributes Reference

Actions have no attributes: nothing they return can be referenced elsewhere in the configuration.
