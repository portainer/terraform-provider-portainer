# portainer_stack_migrate (Action)

The `portainer_stack_migrate` action migrates a stack from one environment (endpoint) to another: Portainer re-creates it in the target environment and then removes the original.

> **Requirements:** Terraform >= 1.14 (actions). OpenTofu does not support actions; there, and with older Terraform, use the [`portainer_stack_migrate` resource](../resources/stack_migrate.md), which runs the same operation when it is created.

## Example Usage

### Run it from a lifecycle `action_trigger`

```hcl
action "portainer_stack_migrate" "to_prod" {
  config {
    stack_id           = 7
    target_endpoint_id = 2
  }
}

resource "terraform_data" "promotion" {
  input = var.promote

  lifecycle {
    action_trigger {
      events    = [after_update]
      condition = var.promote
      actions   = [action.portainer_stack_migrate.to_prod]
    }
  }
}
```

### Run it on demand

```shell
terraform apply -invoke action.portainer_stack_migrate.to_prod
```

## Lifecycle & Behavior

- The action runs only when it is invoked: from an `action_trigger` on the events listed there, or with `terraform apply -invoke`. A plan lists the invocations it would run; nothing is stored in state, so there is nothing to destroy and no `triggers` argument is needed to run it again.
- It sends the same requests as the `portainer_stack_migrate` resource does when it is created, with the same defaults, and fails the apply with the same errors.

## Schema

### Required

- `stack_id` (Number) Stack identifier to migrate.
- `target_endpoint_id` (Number) Target environment (endpoint) identifier to migrate the stack to.

### Optional

- `endpoint_id` (Number) Optional source environment (endpoint) identifier. Required for stacks created before Portainer 1.18.0.
- `is_helm` (Boolean) Whether the stack is a Helm release on Kubernetes. Business Edition only. Only sent when set to true.
- `stack_name` (String) New name for the stack after migration. If not set, the original name is kept.
- `swarm_id` (String) Swarm cluster identifier (required when migrating to a Swarm environment).

## Attributes Reference

Actions have no attributes: nothing they return can be referenced elsewhere in the configuration.
