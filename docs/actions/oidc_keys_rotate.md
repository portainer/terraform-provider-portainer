# portainer_oidc_keys_rotate (Action)

> **Requires Portainer Business Edition 3.1 or later.**

**Portainer Business Edition 3.1.0 serves the OIDC provider only when started with the `oidc` feature flag**: `--feat=oidc` (or the environment variable `FEATURE_FLAG=oidc`; Helm chart: `--set "feature.flags[0]=--feat=oidc"`). Without it every OIDC API call fails with an error that says so.

Rotates the signing key of Portainer's OIDC provider. From then on tokens are signed with a new key; the replaced key stays published, so tokens it signed verify until they expire. Rotating again before they expire refuses them.

> **Requirements:** Terraform >= 1.14 (actions). OpenTofu does not support actions; there, and with older Terraform, use the [`portainer_oidc_keys_rotate` resource](../resources/oidc_keys_rotate.md), which runs the same operation when it is created.

## Example Usage

### Run it on demand

```hcl
action "portainer_oidc_keys_rotate" "now" {
  config {}
}
```

```shell
terraform apply -invoke action.portainer_oidc_keys_rotate.now
```

## Lifecycle & Behavior

- The action runs only when it is invoked: from an `action_trigger` or with `terraform apply -invoke`. Nothing is stored in state.
- It sends the same request as the `portainer_oidc_keys_rotate` resource does when it is created, and fails the apply with the same errors.
