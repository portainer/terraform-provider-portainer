# portainer_kubernetes_cluster_upgrade (Action)

> **Business Edition only.** This endpoint does not exist in Portainer CE.

The `portainer_kubernetes_cluster_upgrade` action upgrades a Kubernetes cluster provisioned by Portainer to the next stable version.

> **Requirements:** Terraform >= 1.14 (actions). OpenTofu does not support actions; there, and with older Terraform, use the [`portainer_kubernetes_cluster_upgrade` resource](../resources/kubernetes_cluster_upgrade.md), which runs the same operation when it is created.

## Example Usage

### Run it from a lifecycle `action_trigger`

```hcl
action "portainer_kubernetes_cluster_upgrade" "prod" {
  config {
    endpoint_id = 3
  }
}

resource "terraform_data" "upgrade_window" {
  input = var.upgrade_window

  lifecycle {
    action_trigger {
      events  = [after_update]
      actions = [action.portainer_kubernetes_cluster_upgrade.prod]
    }
  }
}
```

### Run it on demand

```shell
terraform apply -invoke action.portainer_kubernetes_cluster_upgrade.prod
```

## Lifecycle & Behavior

- The action runs only when it is invoked: from an `action_trigger` on the events listed there, or with `terraform apply -invoke`. A plan lists the invocations it would run; nothing is stored in state, so there is nothing to destroy and no `triggers` argument is needed to run it again.
- It sends the same requests as the `portainer_kubernetes_cluster_upgrade` resource does when it is created, with the same defaults, and fails the apply with the same errors.
