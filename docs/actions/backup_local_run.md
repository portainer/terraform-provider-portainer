# portainer_backup_local_run (Action)

> **Business Edition only.** This endpoint does not exist in Portainer CE.

The `portainer_backup_local_run` action runs a local backup once, outside the schedule configured with `portainer_backup_local_settings`.

> **Requirements:** Terraform >= 1.14 (actions). OpenTofu does not support actions; there, and with older Terraform, use the [`portainer_backup_local_run` resource](../resources/backup_local_run.md), which runs the same operation when it is created.

## Example Usage

### Run it from a lifecycle `action_trigger`

```hcl
action "portainer_backup_local_run" "now" {}

resource "terraform_data" "release" {
  input = var.release

  lifecycle {
    action_trigger {
      events  = [before_update]
      actions = [action.portainer_backup_local_run.now]
    }
  }
}
```

### Run it on demand

```shell
terraform apply -invoke action.portainer_backup_local_run.now
```

## Lifecycle & Behavior

- The action runs only when it is invoked: from an `action_trigger` on the events listed there, or with `terraform apply -invoke`. A plan lists the invocations it would run; nothing is stored in state, so there is nothing to destroy and no `triggers` argument is needed to run it again.
- It sends the same requests as the `portainer_backup_local_run` resource does when it is created, with the same defaults, and fails the apply with the same errors.
- The path and outcome Portainer reports after the run are shown as a progress message.

## Arguments Reference

The action takes no arguments: its `config` block can be left out.

## Attributes Reference

Actions have no attributes: nothing they return can be referenced elsewhere in the configuration.
