# portainer_webhook_execute (Action)

The `portainer_webhook_execute` action calls a Portainer webhook: a service webhook by `token` (restarts the service), or the Git update webhook of a stack (`stack_id`) or an edge stack (`edge_stack_id`). Set exactly one of them.

> Webhooks currently work only on Portainer Business Edition.

> **Requirements:** Terraform >= 1.14 (actions). OpenTofu does not support actions; there, and with older Terraform, use the [`portainer_webhook_execute` resource](../resources/webhook_execute.md), which runs the same operation when it is created.

## Example Usage

### Run it from a lifecycle `action_trigger`

```hcl
action "portainer_webhook_execute" "redeploy" {
  config {
    stack_id = var.stack_webhook_id
  }
}

resource "terraform_data" "image" {
  input = var.image_tag

  lifecycle {
    action_trigger {
      events  = [after_update]
      actions = [action.portainer_webhook_execute.redeploy]
    }
  }
}
```

### Run it on demand

```shell
terraform apply -invoke action.portainer_webhook_execute.redeploy
```

## Lifecycle & Behavior

- The action runs only when it is invoked: from an `action_trigger` on the events listed there, or with `terraform apply -invoke`. A plan lists the invocations it would run; nothing is stored in state, so there is nothing to destroy and no `triggers` argument is needed to run it again.
- It sends the same requests as the `portainer_webhook_execute` resource does when it is created, with the same defaults, and fails the apply with the same errors.
- Webhooks are public endpoints: the request carries no API key, exactly as with the resource.

### Optional

- `edge_stack_id` (String) Edge Stack ID for triggering edge stack GitOps update
- `stack_id` (String) Stack ID for triggering stack GitOps update
- `token` (String) Webhook token for service restart webhook. Action attributes cannot be marked sensitive: set it from a sensitive variable so Terraform redacts it in its output.

Actions have no attributes: nothing they return can be referenced elsewhere in the configuration.
