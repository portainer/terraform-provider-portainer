# portainer_edge_stack_webhook (Action)

The `portainer_edge_stack_webhook` action triggers the webhook of an edge stack, which makes Portainer pull its Git repository and redeploy it.

> Webhooks currently work only on Portainer Business Edition.

> **Requirements:** Terraform >= 1.14 (actions). OpenTofu does not support actions; there, and with older Terraform, use the [`portainer_edge_stack_webhook` resource](../resources/edge_stack_webhook.md), which runs the same operation when it is created.

## Example Usage

### Run it from a lifecycle `action_trigger`

```hcl
action "portainer_edge_stack_webhook" "redeploy" {
  config {
    webhook_id = "4c1b2a3e-0000-4000-8000-000000000000"
  }
}

resource "terraform_data" "release" {
  input = var.release

  lifecycle {
    action_trigger {
      events  = [after_update]
      actions = [action.portainer_edge_stack_webhook.redeploy]
    }
  }
}
```

### Run it on demand

```shell
terraform apply -invoke action.portainer_edge_stack_webhook.redeploy
```

## Lifecycle & Behavior

- The action runs only when it is invoked: from an `action_trigger` on the events listed there, or with `terraform apply -invoke`. A plan lists the invocations it would run; nothing is stored in state, so there is nothing to destroy and no `triggers` argument is needed to run it again.
- It sends the same requests as the `portainer_edge_stack_webhook` resource does when it is created, with the same defaults, and fails the apply with the same errors.
