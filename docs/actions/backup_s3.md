# portainer_backup_s3 (Action)

> **Business Edition only.** This endpoint does not exist in Portainer CE.

The `portainer_backup_s3` action backs the Portainer instance up to an S3 or S3-compatible bucket once.

> **Requirements:** Terraform >= 1.14 (actions). OpenTofu does not support actions; there, and with older Terraform, use the [`portainer_backup_s3` resource](../resources/backup_s3.md), which runs the same operation when it is created.

## Example Usage

### Run it from a lifecycle `action_trigger`

```hcl
action "portainer_backup_s3" "nightly" {
  config {
    access_key_id      = var.s3_access_key_id
    secret_access_key  = var.s3_secret_access_key
    bucket_name        = "portainer-backups"
    region             = "eu-central-1"
    s3_compatible_host = "https://s3.eu-central-1.amazonaws.com"
    password           = var.backup_password
  }
}

resource "terraform_data" "release" {
  input = var.release

  lifecycle {
    action_trigger {
      events  = [before_update]
      actions = [action.portainer_backup_s3.nightly]
    }
  }
}
```

### Run it on demand

```shell
terraform apply -invoke action.portainer_backup_s3.nightly
```

## Lifecycle & Behavior

- The action runs only when it is invoked: from an `action_trigger` on the events listed there, or with `terraform apply -invoke`. A plan lists the invocations it would run; nothing is stored in state, so there is nothing to destroy and no `triggers` argument is needed to run it again.
- It sends the same requests as the `portainer_backup_s3` resource does when it is created, with the same defaults, and fails the apply with the same errors.
- `secret_access_key` and `password` are required: unlike the resource, the action has no `*_wo` twins. Set the secrets from sensitive variables so Terraform redacts them in its output.
- Like the resource, a `cron_rule` is sent along and becomes Portainer's S3 backup schedule.

## Schema

### Required

- `access_key_id` (String) Sensitive S3 access key identifier used to upload the Portainer backup archive. Action attributes cannot be marked sensitive: set it from a sensitive variable so Terraform redacts it in its output.
- `bucket_name` (String) Name of the S3 bucket where the Portainer backup archive will be stored.
- `password` (String) Sensitive password used to encrypt the Portainer backup archive before upload. Action attributes cannot be marked sensitive: set it from a sensitive variable so Terraform redacts it in its output.
- `region` (String) AWS or S3-compatible region of the destination bucket.
- `s3_compatible_host` (String) Endpoint URL of the S3 or S3-compatible service used for the backup upload.
- `secret_access_key` (String) Sensitive S3 secret access key paired with `access_key_id`. Action attributes cannot be marked sensitive: set it from a sensitive variable so Terraform redacts it in its output.

### Optional

- `cron_rule` (String) Optional cron expression that schedules recurring S3 backups in Portainer.

## Attributes Reference

Actions have no attributes: nothing they return can be referenced elsewhere in the configuration.
