# portainer_sshkeygen (Ephemeral Resource)

The `portainer_sshkeygen` ephemeral resource has Portainer generate an SSH key pair (`POST /sshkeygen`) without writing the private key to the plan or the state, unlike the [`portainer_sshkeygen` resource](../resources/sshkeygen.md).

> **Requirements:** Terraform >= 1.10 or OpenTofu >= 1.11 (ephemeral resources).

## Example Usage

```hcl
ephemeral "portainer_sshkeygen" "deploy" {}

# e.g. hand the private key to a write-only attribute for this run only
```

## Lifecycle & Behavior

Portainer stores nothing for the pair, so there is nothing to close. **A new pair is generated in every `plan` and `apply`**, so use it only where the key is needed for the run itself (a provisioner, a write-only argument); a key that must stay the same across runs belongs in the resource.

## Arguments Reference

This ephemeral resource takes no arguments.
