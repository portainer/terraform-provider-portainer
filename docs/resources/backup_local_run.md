# portainer_backup_local_run (Resource)

> **Business Edition only.** This endpoint does not exist in Portainer CE.

Runs a local backup once, outside the schedule.

> **See also:** the [`portainer_backup_local_run` action](../actions/backup_local_run.md) (Terraform >= 1.14) runs the same operation on demand or from a lifecycle `action_trigger`, without a resource in state.

## Example Usage

```hcl
resource "portainer_backup_local_run" "before_upgrade" {
  triggers = {
    version = var.portainer_version
  }
}
```

## Schema

### Optional

- `triggers` (Map of String) Arbitrary values that force another backup run when they change. A backup is a one-shot action, so without a trigger the resource runs once and then stays put.

### Read-Only

- `failed` (Boolean) Whether Portainer reports the run as failed.
- `id` (String) Identifier of the resource.
- `path` (String) Path on the Portainer host where the archive was written, as reported after the run.
- `timestamp` (String) UTC timestamp Portainer reports for the run.
