# portainer_oidc_user_sessions_end (Resource)

> **Requires Portainer Business Edition 3.1 or later.** On Community Edition or an older server the apply fails with an error that says so.

**Portainer Business Edition 3.1.0 serves the OIDC provider only when started with the `oidc` feature flag**: `--feat=oidc` (or the environment variable `FEATURE_FLAG=oidc`; Helm chart: `--set "feature.flags[0]=--feat=oidc"`). Without it every OIDC API call fails with an error that says so.

Signs a user out of every client and add-on that signed them in through Portainer's OIDC provider. Their tokens are revoked at once.

> **See also:** the [`portainer_oidc_user_sessions_end` action](../actions/oidc_user_sessions_end.md) (Terraform >= 1.14) runs the same operation on demand or from a lifecycle `action_trigger`, without a resource in state.

## Example Usage

```hcl
resource "portainer_oidc_user_sessions_end" "this" {
  user_id = var.user_id

  triggers = {
    reason = var.reason
  }
}
```
