# portainer_kubernetes_environment_config (Resource)

The `portainer_kubernetes_environment_config` resource manages the Kubernetes features configuration of a Kubernetes environment, the settings the Portainer UI shows under **Environments → (cluster) → Kubernetes configuration**: load balancers, metrics, resource over-commit, access to the `default` namespace and the storage classes users may pick.

Ingress classes are not part of this resource; manage them with [`portainer_kubernetes_ingresscontrollers`](kubernetes_ingresscontrollers.md).

## Example Usage

```hcl
resource "portainer_kubernetes_environment_config" "cluster" {
  endpoint_id = 4

  use_load_balancer               = true
  use_server_metrics              = true
  enable_resource_over_commit     = false
  resource_over_commit_percentage = 80
  restrict_default_namespace      = true

  storage_class {
    name                   = "local-path"
    provisioner            = "rancher.io/local-path"
    access_modes           = ["RWO"]
    allow_volume_expansion = false
  }
}
```

## Lifecycle & Behavior

- Portainer stores this configuration with the environment and replaces it as a whole on every update. The provider reads the current configuration first and changes only the managed settings, so snapshots, detected cluster features and ingress classes are kept.
- Every argument is optional. One that is left out keeps the value configured in Portainer, and the resource reads all of them back, so changes made in the Portainer UI show up in the plan.
- `storage_class` blocks replace the list of enabled storage classes when at least one is set.
- Destroying the resource only removes it from state; the environment keeps its configuration.

## Schema

### Required

- `endpoint_id` (Number) ID of the Kubernetes environment whose configuration is managed. Changing this value forces resource recreation.

### Optional

- `allow_none_ingress_class` (Boolean) Whether users may create ingresses without an ingress class.
- `enable_resource_over_commit` (Boolean) Whether namespace quotas may add up to more than the cluster's capacity.
- `ingress_availability_per_namespace` (Boolean) Whether ingress classes can be made available per namespace.
- `resource_over_commit_percentage` (Number) Share of the cluster's resources (1-100) namespaces may reserve when over-commit is disabled.
- `restrict_default_namespace` (Boolean) Whether the `default` namespace is restricted to administrators.
- `storage_class` (Block List) Storage classes users may pick for their volumes. When set, the list replaces the enabled storage classes; leave it out to keep the ones configured in Portainer. (see [below for nested schema](#nestedblock--storage_class))
- `use_load_balancer` (Boolean) Whether users may expose applications through a LoadBalancer service.
- `use_server_metrics` (Boolean) Whether Portainer reads metrics from the cluster's metrics server.

### Read-Only

- `id` (String) Identifier of the environment whose configuration is managed.

<a id="nestedblock--storage_class"></a>
### Nested Schema for `storage_class`

Required:

- `name` (String) Name of the Kubernetes StorageClass.
- `provisioner` (String) Provisioner of the StorageClass, e.g. `rancher.io/local-path`.

Optional:

- `access_modes` (List of String) Access modes users may request, e.g. `RWO` or `RWX`.
- `allow_volume_expansion` (Boolean) Whether volumes of this class may be expanded.

## Import

The configuration can be imported using the numeric environment ID:

```shell
terraform import portainer_kubernetes_environment_config.cluster 4
```
