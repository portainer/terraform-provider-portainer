# portainer_shared_git_credential (Resource)

The `portainer_shared_git_credential` resource allows you to manage shared git credentials in Portainer. Shared git credentials are available to all users and are managed by administrators.

> Requires Portainer Business Edition 2.39+. Business Edition 3.1 and later also require `url_pattern`
> (it stays optional in the schema for older releases; without it Portainer 3.1 rejects the credential with
> "At least one URL pattern is required").

## Example Usage

### Basic authentication
```hcl
resource "portainer_shared_git_credential" "example" {
  name               = "my-git-credential"
  username           = "git-user"
  password           = "git-password"
  authorization_type = 0
  url_pattern        = "github.com/my-org/*" # required by Business Edition 3.1 and later
}
```

### Token authentication
```hcl
resource "portainer_shared_git_credential" "token_example" {
  name               = "my-git-token"
  username           = "git-user"
  password           = "ghp_xxxxxxxxxxxxxxxxxxxx"
  authorization_type = 1
}
```

### Limited to repositories matching a URL pattern
```hcl
resource "portainer_shared_git_credential" "github_org" {
  name        = "github-org"
  username    = "git-user"
  password    = "ghp_xxxxxxxxxxxxxxxxxxxx"
  url_pattern = "github.com/portainer/*"
}
```

## Lifecycle & Behavior
Shared git credentials are created via the `/cloud/gitcredentials` API.

Only administrators can create, update, or delete shared git credentials.

The `password` field is sensitive and will not be displayed in plan output.

- To destroy a shared git credential:
```hcl
terraform destroy
```

- To update a shared git credential, update the relevant fields and re-apply:
```hcl
terraform apply
```

## Schema

### Required

- `name` (String) Name of the shared git credential
- `password` (String, Sensitive) Password or token for git authentication
- `username` (String) Username for git authentication

### Optional

- `authorization_type` (Number) Authorization type: 0 = Basic, 1 = Token
- `url_pattern` (String) Repository URL pattern the credential is offered for (e.g. `github.com/portainer/*`). Business Edition 2.45 or later, and required by Business Edition 3.1 and later. Left out, it is not sent and Portainer keeps its current value.

### Read-Only

- `id` (String) Identifier of the shared git credential.
- `user_id` (Number) User ID of the credential owner

## Notes on Arguments and Attributes

- `authorization_type`: Authorization type: `0` = Basic (default), `1` = Token.
- `url_pattern`: Business Edition 2.45 or later; required by Business Edition 3.1 and later.

## Import

Shared git credentials can be imported using their ID:

```shell
terraform import portainer_shared_git_credential.example 123
```

The import reads `url_pattern` when the credential has one; `password` is not returned by Portainer and has to
be set in the configuration.
