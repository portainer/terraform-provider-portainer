# portainer_backup_local_settings (Resource)

> **Business Edition only.** This endpoint does not exist in Portainer CE.

Manages Portainer's scheduled backup to local storage on the Portainer host, including how long archives are kept.

## Example Usage

```hcl
resource "portainer_backup_local_settings" "nightly" {
  cron_rule      = "0 3 * * *"
  retention_days = 14

  # Required in FIPS mode (Portainer BE 3.1+); keeps it out of state:
  # password_wo         = var.backup_archive_password
  # password_wo_version = 1
}
```

## Schema

### Optional

> **NOTE**: [Write-only arguments](https://developer.hashicorp.com/terraform/language/resources/ephemeral#write-only-arguments) are supported in Terraform 1.11 and later.

- `cron_rule` (String) Cron expression for the scheduled local backup (for example `0 2 * * *`). Leave unset to keep the schedule off and back up only on demand with `portainer_backup_local_run`.
- `password` (String, Sensitive) Password the scheduled local backup archives are encrypted with. Leave unset for unencrypted archives. Required when Portainer runs in FIPS mode (Business Edition 3.1 or later), which refuses unencrypted backups. Stored in state as a sensitive value; use `password_wo` to keep it out of state.
- `password_wo` (String, Sensitive, [Write-only](https://developer.hashicorp.com/terraform/language/resources/ephemeral#write-only-arguments)) Write-only password used to encrypt the local backup archives (supports ephemeral values; never stored in Terraform state). Conflicts with `password`. Requires Terraform 1.11 or later.
- `password_wo_version` (Number) Version of `password_wo`. Increment it to send a new value.
- `retention_days` (Number) How many days Portainer keeps local backup archives before pruning them. Zero keeps them indefinitely.

### Read-Only

- `id` (String) Identifier of the resource.
- `last_run_failed` (Boolean) Whether the most recent scheduled local backup failed.
- `last_run_path` (String) Path on the Portainer host where the most recent local backup archive was written.
- `last_run_timestamp` (String) UTC timestamp of the most recent scheduled local backup, empty when none has run.

## FIPS mode (Portainer BE 3.1+)

A Portainer Business Edition 3.1 instance running in FIPS mode refuses unencrypted backups, and a schedule without a password stops running there. Set `password` (or `password_wo` with `password_wo_version`) when the instance runs in FIPS mode. The password is only sent when configured, so older servers are unaffected, and it is never read back.

## Attributes Reference

Removing the resource stops managing the settings; Portainer has no endpoint to clear them.

## Import

The local backup settings are instance-wide, so any import ID works:

```shell
terraform import portainer_backup_local_settings.example portainer-backup-local-settings
```
