# portainer_oidc_client (Resource)

> **Requires Portainer Business Edition 3.1 or later.** On Community Edition or an older server the create fails with an error that says so. The OIDC provider itself is switched on with the `oidc_provider` block of [`portainer_settings`](settings.md) (`public_url`).

**Portainer Business Edition 3.1.0 serves the OIDC provider only when started with the `oidc` feature flag**: `--feat=oidc` (or the environment variable `FEATURE_FLAG=oidc`; Helm chart: `--set "feature.flags[0]=--feat=oidc"`). Without it every OIDC API call fails with an error that says so.

Registers an application or add-on (Grafana, Vault, an internal portal, ...) that signs users in through Portainer's built-in OIDC provider. Portainer generates the OAuth client ID and a first client secret; the application is configured with them and with the issuer `<public_url>/api/oidc`.

## Example Usage

```hcl
resource "portainer_settings" "this" {
  oidc_provider {
    public_url = "https://portainer.example.com"
  }
}

resource "portainer_oidc_client" "grafana" {
  name             = "Grafana"
  description      = "Dashboards"
  redirect_uris    = ["https://grafana.example.com/login/generic_oauth"]
  homepage_url     = "https://grafana.example.com"
  show_in_launcher = true
  groups_claim     = true

  team_access_policies = {
    (portainer_team.ops.id) = 1
  }
}

output "grafana_oauth_client_id" {
  value = portainer_oidc_client.grafana.client_id
}

output "grafana_oauth_client_secret" {
  value     = portainer_oidc_client.grafana.client_secret
  sensitive = true
}
```

## Schema

### Required

- `name` (String) Name of the client, shown in Portainer and in its launcher.
- `redirect_uris` (List of String) Redirect URIs the client may send users back to after they sign in, for example `https://grafana.example.com/login/generic_oauth`.

### Optional

- `all_users` (Boolean) Whether every Portainer user may sign in to the client. Otherwise only the users and teams in `user_access_policies` and `team_access_policies` may. Defaults to `false`.
- `description` (String) Description of the client, shown in Portainer's launcher.
- `enabled` (Boolean) Whether the client is switched on. While it is off no one can sign in to it and its tokens are refused. Portainer creates clients switched on; `false` is applied by an update right after the create. Defaults to `true`.
- `groups_claim` (Boolean) Whether the client's tokens carry the user's team names in a `groups` claim. Defaults to `false`.
- `homepage_url` (String) URL Portainer's launcher opens for the client.
- `permission` (String) What the client's tokens may do in Portainer's API: `none` (sign-in only), `read-only` or `act-as-user`. Defaults to `none`.
- `post_logout_redirect_uris` (List of String) URIs the client may send users to after they sign out.
- `secret_expires_at` (Number) Unix time the first client secret expires at; unset or 0 for never. It only applies when the client is created, so changing it replaces the client. Further secrets are managed with `portainer_oidc_client_secret`.
- `show_in_launcher` (Boolean) Whether the client is listed in Portainer's launcher for the users who may sign in to it. Defaults to `false`.
- `team_access_policies` (Map of Number) Teams whose members may sign in to the client: map of team IDs to role IDs (e.g. teamID -> roleID). Portainer stores a role with each policy.
- `user_access_policies` (Map of Number) Users who may sign in to the client: map of user IDs to role IDs (e.g. userID -> roleID). Portainer stores a role with each policy.

### Read-Only

- `client_id` (String) OAuth client ID Portainer generated, which the application is configured with.
- `client_secret` (String, Sensitive) First client secret. Portainer returns it exactly once, at creation, so it is only ever available from the state written by that apply; it is null after an import.
- `client_secret_id` (String) Identifier of the first client secret, to import it into `portainer_oidc_client_secret` (for example to regenerate it). Null after an import.
- `id` (String) Numeric Portainer identifier of the OIDC client (not the OAuth `client_id`).

## Notes on Arguments and Attributes

- `client_secret`: Portainer returns the first secret only in the response to the create request. It is kept in state (marked sensitive) from that apply on, and is null after an import. Treat the state as a secret, or add a secret with [`portainer_oidc_client_secret`](oidc_client_secret.md) and use that one.
- `secret_expires_at`: Only the create request takes it, so changing it replaces the client (with a new `client_id` and secret).
- `enabled`: Portainer creates every client switched on; with `enabled = false` the provider switches it off by an update right after the create.
- `user_access_policies`, `team_access_policies`: Who may sign in when `all_users` is `false`. Portainer stores a role ID with each policy, as for environments.
- `id`: Numeric Portainer ID of the client: the import ID, and the `client_id` that `portainer_oidc_client_secret`, `portainer_oidc_client_sessions_end` and `portainer_oidc_client_sessions` take. The OAuth client ID is the `client_id` attribute.

## Attributes Reference

Every update sends the whole configuration: arguments removed from it are cleared in Portainer. A client deleted outside Terraform disappears from state on the next refresh.

## Import

OIDC clients can be imported using their numeric ID. The first client secret cannot be imported: Portainer never returns it again, so `client_secret` and `client_secret_id` stay null.

```shell
terraform import portainer_oidc_client.example 3
```

### Import by identity

Terraform 1.12 and later can also import by resource identity: the object's numeric ID as `id` in an `import` block. The ID string above keeps working.

```hcl
import {
  to       = portainer_oidc_client.example
  identity = {
    id = "3"
  }
}
```

The [`portainer_oidc_client` list resource](../list-resources/oidc_client.md) (Terraform 1.14+) finds the clients to import.
