# portainer_backup_azure_execute (Resource)

> **Business Edition only.** This endpoint does not exist in Portainer CE.

Runs an Azure Blob backup once, outside the schedule.

> **See also:** the [`portainer_backup_azure_execute` action](../actions/backup_azure_execute.md) (Terraform >= 1.14) runs the same operation on demand or from a lifecycle `action_trigger`, without a resource in state.

## Example Usage

```hcl
resource "portainer_backup_azure_execute" "adhoc" {
  auth_method          = "storageAccountKey"
  storage_account_name = "acmebackups"
  container_name       = "portainer"
  storage_account_key  = var.azure_storage_key

  triggers = {
    before_upgrade = var.portainer_version
  }
}
```
