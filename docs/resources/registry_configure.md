# portainer_registry_configure (Resource)

The `portainer_registry_configure` resource applies the authentication and TLS configuration of an existing registry, which is a separate Portainer endpoint from the registry object itself.

## Example Usage

```hcl
resource "portainer_registry" "harbor" {
  name = "harbor"
  url  = "registry.example.com"
  type = 3
}

resource "portainer_registry_configure" "harbor" {
  registry_id    = portainer_registry.harbor.id
  authentication = true
  username       = "robot$ci"
  password       = var.registry_password
  tls            = true
  tls_ca_cert    = file("ca.pem")
}
```

## Schema

### Required

- `authentication` (Boolean) Whether the registry requires authentication. When false, Portainer ignores `username` and `password`.
- `registry_id` (Number) Identifier of the registry to configure.

### Optional

> **NOTE**: [Write-only arguments](https://developer.hashicorp.com/terraform/language/resources/ephemeral#write-only-arguments) are supported in Terraform 1.11 and later.

- `password` (String, Sensitive) Password or token paired with `username`. Portainer never returns it, so it cannot be checked for drift. Stored in state as a sensitive value; use `password_wo` to keep it out of state.
- `password_wo` (String, Sensitive, [Write-only](https://developer.hashicorp.com/terraform/language/resources/ephemeral#write-only-arguments)) Write-only registry password (supports ephemeral values; never stored in Terraform state). Conflicts with `password`. Requires Terraform 1.11 or later.
- `password_wo_version` (Number) Version of `password_wo`. Increment it to send a new value.
- `region` (String) AWS region of an ECR registry. Ignored by other registry types.
- `tls` (Boolean) Whether Portainer contacts the registry over TLS.
- `tls_ca_cert` (String, Sensitive) PEM-encoded CA certificate used to verify the registry's certificate. Stored in state as a sensitive value.
- `tls_cert` (String, Sensitive) PEM-encoded client certificate presented to the registry. Stored in state as a sensitive value.
- `tls_key` (String, Sensitive) PEM-encoded client private key paired with `tls_cert`. Stored in state as a sensitive value; use `tls_key_wo` to keep it out of state.
- `tls_key_wo` (String, Sensitive, [Write-only](https://developer.hashicorp.com/terraform/language/resources/ephemeral#write-only-arguments)) Write-only PEM-encoded TLS client key (supports ephemeral values; never stored in Terraform state). Conflicts with `tls_key`. Requires Terraform 1.11 or later.
- `tls_key_wo_version` (Number) Version of `tls_key_wo`. Increment it to send a new value.
- `tls_skip_verify` (Boolean) Whether to skip verification of the registry's TLS certificate.
- `username` (String) Username used to authenticate against the registry. Required when `authentication` is true.

### Read-Only

- `id` (String) Identifier of the configuration: <registry_id>/configure.

## Notes on Arguments and Attributes

- `registry_id`: Changing it replaces the resource.
- `id`: Composite identifier in the form `<registry_id>/configure`.

## Attributes Reference

Portainer has no endpoint to read a registry's configuration back or to clear it, so this resource cannot detect drift, and destroying it only stops managing the configuration — the registry keeps the settings it was given.
